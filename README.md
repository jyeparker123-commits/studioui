# StudioUI

**One plugin. Every modality. Image · Video · GIF · Music · AI Chat Companions — all inside WordPress.**

StudioUI turns any WordPress site into a full multi-modal AI studio. Generate images,
video, animated GIFs, and music — and talk to persistent AI chat companions with voice —
from a single, white-labelled interface your users never have to leave.

👉 **Live demo & downloads: [studioui.ai](https://studioui.ai)**

---

## ✨ Features

- 🎨 **Image generation** — multiple providers, model picker, per-model cost control
- 🎬 **Video & 🌀 GIF** — text-to-video and animated output in the same UI
- 🎵 **Music** — generate full tracks from a prompt
- 💬 **AI chat companions** — persistent characters with per-voice TTS
- 🔌 **15+ providers** — pooled keys with automatic failover
- 🏷️ **White-label by default** — your brand, not ours
- 🧩 **Drop-in WordPress plugin** — shortcodes, no rebuild required

## 💸 Two ways to run it

| | **Free** | **Pro** |
|---|---|---|
| Hosting | Hosted credits (we run the compute) | Bring-your-own keys / self-host |
| Cost | Free tier, daily allowance | One-time / annual license |
| Best for | Trying it out, low volume | Studios, agencies, full control |

## 🚀 Quick start

1. Download the plugin from **[studioui.ai](https://studioui.ai)**
2. Upload via **Plugins → Add New → Upload** in WordPress
3. Activate, drop the `[studioui]` shortcode on any page
4. Start generating — Free tier works out of the box
